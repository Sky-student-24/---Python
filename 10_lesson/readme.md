1. Убедись, что у тебя установлен Allure и плагин для Pytest:

pip install allure-pytest


2. Запусти тесты с генерацией отчета:

pytest путь/к/твоей/папке --alluredir=путь/к/папке/для/отчетов


3. Для просмотра отчета используй команду:

allure serve путь/к/папке/для/отчетов


Эта команда откроет отчет в браузере.
